Virtual Fun Run Management System (VFRMS) was my Diploma Final Year Project. 
VFRMS is where organizer and participant go for Virtual Fun Run.

The organizer, can manage their Fun Run, analytics and Etc.
The participant, can search for Fun run, view their run, and all related to the Fun Run associated with the participant.

It has been done and completed using PHP without any framework. 

This is the version of that system using Laravel as framework.
